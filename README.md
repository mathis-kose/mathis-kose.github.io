# mathis-projects.com

Shop und Portfolio von Mathis Kose (MK-Projects), statisch auf GitHub Pages.

- Seiten: `index.html` (Bento-Landing), `shop.html`, `tiger.html`, `orchideen.html`, Story-Seiten `*-story.html`, `ueber-mich.html`, `kontakt.html`, Rechtliches als Entwurf (noindex).
- Design: `css/mk.css` (Hell/Dunkel per `theme.js`), `mk.js` (Animationen, Galerie, Story-Scroll). Schrift Poppins liegt lokal in `fonts/`.
- Grafiken: `img/svg/` (Tiger aus dem Foto vektorisiert, Favicon), Fotos als WebP in `img/shop/`.
- Platzhalter im Quelltext suchen: `class="todo"`.
- Zeilenenden: CRLF.
